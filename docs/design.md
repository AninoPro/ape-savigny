# Note de design

**Objectif** : présenter l'APE (projets, lien avec l'école, bien-être des enfants), recruter des bénévoles, donner un contact simple. Aucun nom de membre du bureau (il change).

**Idée** : le petit train du marché de Noël devient la frise de l'année scolaire (une gare par projet).

**Couleurs** : lilas (celui des flyers de l'APE), violet foncé pour le texte, jaune soleil pour les actions, menthe en appui.
**Polices** : Fredoka (titres), Atkinson Hyperlegible (texte), hébergées localement (pas d'appel à Google).
**Accessibilité** : contrastes AA, focus visible, lien d'évitement, `prefers-reduced-motion`, mobile d'abord, texte vrai (pas d'image de texte).
**Mouvement** : un seul, le train qui entre au chargement.
